# LicheeRV Nano — классическая видеоаналитика

Проект модульной системы классической видеоаналитики для обнаружения нештатных ситуаций внутри помещений на **LicheeRV Nano (SG2002)** с камерой **GC4653**.

## Детекторы

1. Обнаружение проникновения движущихся объектов площадью от 0,5 м².
2. Обнаружение дыма площадью от 0,5 м² при контрасте не менее 20%.
3. Обнаружение смещения протяжённых объектов от 5 см в плоскости, перпендикулярной оптической оси камеры.

## Архитектурные принципы

- Единый видеоконвейер и независимые модули детектирования.
- Включение/выключение каждого детектора без перезапуска всей системы.
- Возможность независимой и совместной работы детекторов.
- Общий формат событий, конфигурации и диагностики.
- Использование реальной камеры и подготовленных видеозаписей для проверки.
- Основной подход — **классические алгоритмы без нейросетей**.

> Целевые пороги — требования, а не подтверждённые результаты испытаний на устройстве.
